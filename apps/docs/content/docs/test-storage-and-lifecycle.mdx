---
title: 'Test storage and the lifecycle'
description: 'Seed stored values by key, render through the test environment, exercise a loading or failing user backend, and change the signed-in user.'
---

Apps and Widgets. Seed stored values by key in a memory environment, mount your component, then
change the signed-in user. React uses a provider wrapper. Angular mounts a definition with its real
injection context.

## Steps

<Steps>

<Step>

### 1. Import your keys, and dispose the environment after each test

<Tabs items={['React', 'Angular']} defaultValue="React">
<Tab value="React">

```tsx title="src/storage.test.tsx"
import { useStoredState } from '@company/mfe-react'
import { createMfeTestEnvironment } from '@company/mfe-react/testing'
import { act, renderHook, waitFor } from '@testing-library/react'
import { afterEach, expect, it } from 'vitest'

import { draft, units, visits } from './storage.ts'

let environment: ReturnType<typeof createMfeTestEnvironment> | null = null

afterEach(async () => {
  const current = environment
  environment = null
  await current?.dispose()
})
```

</Tab>
<Tab value="Angular">

```ts title="src/storage.test.ts"
import { Component, runInInjectionContext } from '@angular/core'
import { createWidget, injectStoredState } from '@company/mfe-angular'
import { cleanup, createMfeTestEnvironment, mountWidget } from '@company/mfe-angular/testing'
import { afterEach, expect, it } from 'vitest'
import { z } from 'zod'

import { draft, visits } from './storage'

@Component({ selector: 'storage-probe', template: '' })
class StorageProbe {}

const definition = createWidget({
  id: 'lab',
  inputSchema: z.object({}),
  outputSchema: z.object({}),
  component: StorageProbe,
})
let environment: ReturnType<typeof createMfeTestEnvironment> | null = null

afterEach(async () => {
  await cleanup()
  environment?.dispose()
  environment = null
})
```

</Tab>
</Tabs>

Import the keys your code declares. A test never repeats a key's name or schema.

</Step>

<Step>

### 2. Seed values before you render

<Tabs items={['React', 'Angular']} defaultValue="React">
<Tab value="React">

```tsx title="src/storage.test.tsx"
environment = createMfeTestEnvironment({
  definitionId: 'lab',
  storage: [
    [visits, 3],
    [draft, { note: 'rig 4', pinned: true }],
    [units, 'imperial'],
  ],
})
const env = environment
```

</Tab>
<Tab value="Angular">

```ts title="src/storage.test.ts"
environment = createMfeTestEnvironment({
  definitions: [definition],
  storage: {
    values: [
      [visits, 3],
      [draft, { note: 'rig 4', pinned: true }],
    ],
  },
})
const env = environment
```

</Tab>
</Tabs>

Seeds go in every area, `user` included, and belong to the mount's definition. `renderApp` and
`renderWidget` take the same `storage` option. Place steps 2–5 inside an `it` callback.

</Step>

<Step>

### 3. Render inside the mount

<Tabs items={['React', 'Angular']} defaultValue="React">
<Tab value="React">

```tsx title="src/storage.test.tsx"
const { result } = renderHook(() => useStoredState(visits), { wrapper: env.wrapper })

expect(result.current.value).toBe(3)
await act(() => result.current.set(4))
expect(env.mount.storage.peek(visits)).toBe(4)
```

</Tab>
<Tab value="Angular">

```ts title="src/storage.test.ts"
const widget = await mountWidget(definition, { environment: env })
const state = runInInjectionContext(widget.injector, () => injectStoredState(visits))

expect(state.value()).toBe(3)
```

</Tab>
</Tabs>

React's wrapper supplies the mount providers. Angular's `mountWidget` supplies the mount injector.
Run each Angular injector call synchronously inside `runInInjectionContext`.

</Step>

<Step>

### 4. Change the signed-in user

<Tabs items={['React', 'Angular']} defaultValue="React">
<Tab value="React">

```tsx title="src/storage.test.tsx"
env.setShellState({ user: { id: 'u-2', name: 'Sam Reyes' } })

expect(env.mount.storage.peek(draft)).toEqual({ note: 'rig 4', pinned: true })
```

</Tab>
<Tab value="Angular">

```ts title="src/storage.test.ts"
env.setShellState({ user: { id: 'u-2', name: 'Sam Reyes' } })
await widget.whenStable()

const storage = env.runtime.storage.forCaller({ owner: 'lab' })
expect(storage.peek(draft)).toEqual({ note: 'rig 4', pinned: true })
```

</Tab>
</Tabs>

`setShellState` runs the identity change the shell runs. Local and session values stay. User values
are dropped and loaded again for the new user. The old Angular mount may be disposed, so read
through the runtime's storage.

</Step>

<Step>

### 5. Exercise a loading or failing backend

<Tabs items={['React', 'Angular']} defaultValue="React">
<Tab value="React">

```tsx title="src/storage.test.tsx"
const save = () => Promise.resolve(null)
const failing = createMfeTestEnvironment({
  userStorage: { load: () => Promise.reject(new Error('down')), save },
})
const { result } = renderHook(() => useStoredState(units), { wrapper: failing.wrapper })

await waitFor(() => expect(result.current.status).toBe('error'))
expect(result.current.value).toBe('metric')
await failing.dispose()
```

</Tab>
<Tab value="Angular">

```ts title="src/storage.test.ts"
const save = () => Promise.resolve(null)
const failing = createMfeTestEnvironment({
  definitions: [definition],
  storage: { user: { load: () => Promise.reject(new Error('down')), save } },
})
```

</Tab>
</Tabs>

`load: () => new Promise(() => {})` keeps the area loading. `createMemoryUserStorage(rows)` is a
working backend whose `saves` list records what was sent.

</Step>

</Steps>

## Check it works

The suite passes, and the assertions above hold in either order. Pass `shellState` to start with a
different user, groups or theme. The environment carries the rest of the mount too.

| Field           | For                                           |
| --------------- | --------------------------------------------- |
| `telemetry`     | the events, logs and spans the mount recorded |
| `diagnostics`   | what the framework reported                   |
| `navigation`    | where the mount asked to go                   |
| `routerContext` | calling a React route callback                |
| `storageAreas`  | inspecting what was written to the browser    |
| `runtime`       | the registry, the stores and the shell state  |

## Errors

<Callout type="error" title="storage/invalid-value, a perInstance key without an instance">

```text shared
lab failed to bind a stored key camera: expected a stable host-supplied instanceId for a
perInstance key, received undefined.
```

**Fix.** Pass `instanceId` to `createMfeTestEnvironment`, `renderWidget` or `mountWidget`.

</Callout>

<Callout type="error" title="storage/failure, two keys with one name">

```text shared
lab failed to bind the local storage key visits: expected the same schema object every active
consumer already declared, received a different schema object.
```

**Fix.** Import the one key into the test instead of declaring a second copy of it.

</Callout>
