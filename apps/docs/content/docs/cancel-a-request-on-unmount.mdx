---
title: 'Cancel a request on unmount'
description: 'Pass the mount signal to fetch, listeners and timers, so background work stops on disposal.'
---

React `useMfeSignal()` and Angular `injectMfeSignal()` return a signal that aborts when your mount goes away. Pass it to every
request, listener and timer you start outside a route loader. Apps and Widgets.

## Steps

<Steps>

<Step>

### 1. Take the mount's signal

<Tabs items={['React', 'Angular']}>
<Tab value="React">

```tsx title="examples/lab/src/routes/index.tsx (adapted)"
import { useMfeSignal } from '@company/mfe-react'

// Inside your component:
const signal = useMfeSignal()
```

</Tab>
<Tab value="Angular">

```ts title="examples/fieldwork/src/overview.component.ts (adapted)"
import { injectMfeSignal } from '@company/mfe-angular'

// Inside your component constructor:
const signal = injectMfeSignal()
```

</Tab>
</Tabs>

One signal serves the whole mount, so read it once and pass it around.

</Step>

<Step>

### 2. Pass it to the request

<Tabs items={['React', 'Angular']}>
<Tab value="React">

```ts title="examples/lab/src/routes/index.tsx (adapted)"
import { fetch } from '#mfe/fetch'

const response = await fetch('assets?site=north', { signal })
```

</Tab>
<Tab value="Angular">

```ts title="examples/fieldwork/src/overview.component.ts (adapted)"
import { fetch } from '#mfe/fetch'

const response = await fetch('assets?site=north', { signal })
```

</Tab>
</Tabs>

An aborted request rejects with the browser's `AbortError`, which your error handling can ignore.

</Step>

<Step>

### 3. Use it for listeners and timers

<Tabs items={['React', 'Angular']}>
<Tab value="React">

```ts title="examples/lab/src/routes/index.tsx (adapted)"
window.addEventListener('resize', onResize, { signal })

const timer = setInterval(poll, 30_000)
signal.addEventListener('abort', () => clearInterval(timer), { once: true })
```

</Tab>
<Tab value="Angular">

```ts title="examples/fieldwork/src/overview.component.ts (adapted)"
window.addEventListener('resize', onResize, { signal })

const timer = setInterval(poll, 30_000)
signal.addEventListener('abort', () => clearInterval(timer), { once: true })
```

</Tab>
</Tabs>

A listener registered with `{ signal }` removes itself, and a timer needs the one abort handler
above.

</Step>

</Steps>

React route loaders use their `abortController.signal` to cancel with navigation. A mount signal cancels only with mount disposal.
Use component cleanup too when a listener or timer should end before the whole App unmounts.

## Check it works

Open `/lab` in the shell. It prints `signal.aborted` for the live mount, which reads `live` until
the mount is disposed. Navigate away, and any request still in flight is cancelled. React TanStack Query requests cancel when their mount's Query client is disposed. A
second mount of the same definition gets its own signal, so one closing never stops the other.

## Errors

<Tabs items={['React', 'Angular']}>
<Tab value="React">

<Callout type="error" title="mount/failure">

```text
<unmounted> failed to call useMfeSignal: expected a component rendered inside an App or Widget
mount, received a component rendered outside any mount.
```

**Fix.** Move the hook into a component your App or Widget renders. Shell chrome has no mount of its own.

</Callout>

</Tab>
<Tab value="Angular">

<Callout type="error" title="mount/failure">

`injectMfeSignal()` requires a component or service created inside an App or Widget mount.

**Fix.** Call it in the mounted component's constructor or field initializer. Shell providers and components outside a mount cannot read its signal.

</Callout>

</Tab>
</Tabs>
