---
title: 'Add an action to the palette'
description: 'Register actions from React or Angular, and run them through the shell palette or your own button.'
---

Apps and Widgets. Register an action to make it available in the shell command palette. Your container owns its implementation and availability.

<Diagram
  src="/diagrams/capability-actions.svg"
  alt="How React and Angular containers connect to the shell for actions."
  caption="How your container connects to the shell"
>
  Your component registers through `useAction` or `injectAction`. The shell lists the action and
  checks `canExecute` before calling your implementation. Your own button runs the same
  registration. Leaving the component removes it.
</Diagram>

## Steps

<Steps>

<Step>

### 1. Register an action and connect your button

<Tabs items={['React', 'Angular']}>
<Tab value="React">

```tsx title="examples/alert-panel/src/alert-panel.tsx (adapted)"
import { useState } from 'react'
import { allow, deny, useAction } from '@company/mfe-react'

export function AcknowledgeButton() {
  const [acknowledged, setAcknowledged] = useState(false)
  const acknowledge = useAction({
    name: 'acknowledge',
    label: 'Acknowledge alert',
    canExecute: () => (acknowledged ? deny('Already acknowledged.') : allow()),
    execute: () => {
      setAcknowledged(true)
    },
  })
  return <button onClick={() => void acknowledge()}>Acknowledge</button>
}
```

</Tab>
<Tab value="Angular">

```ts title="examples/fieldwork/src/overview.component.ts (adapted)"
import { Component, signal } from '@angular/core'
import { allow, deny, injectAction } from '@company/mfe-angular'

@Component({
  selector: 'fieldwork-acknowledge',
  template: `<button (click)="acknowledge()">Acknowledge</button>`,
})
export class AcknowledgeComponent {
  readonly acknowledged = signal(false)
  readonly acknowledge = injectAction(() => ({
    name: 'acknowledge',
    label: 'Acknowledge alert',
    canExecute: () => (this.acknowledged() ? deny('Already acknowledged.') : allow()),
    execute: () => {
      this.acknowledged.set(true)
    },
  }))
}
```

Use a factory when the registration reads signals. Call `injectAction` in a constructor or field initializer.

</Tab>
</Tabs>

The palette and your button use the same availability checks. A denied action stays visible with its reason.
Keep `canExecute` a state check, and authorize requests in your API.
The registration ends when its component unmounts or injector is destroyed.

</Step>

<Step>
### 2. Choose the lifetime and optional shortcut

Register in a layout component for App-wide actions, or a page component for page actions.
An App action can declare `shortcut: 'o w'`. Widgets cannot register shortcuts.
Use `+` for chords such as `mod+s`, and spaces for sequences. `mod` means Command on macOS and Control elsewhere.
Choose keys that do not conflict with shell shortcuts or other live actions.
See the [shortcut rules](/docs/reference/hooks-and-components#useaction) before assigning keys.

</Step>

</Steps>

## Check it works

Open the palette with Command+K or Control+K while your component is mounted. Find “Acknowledge alert”, then run it.
Reopen the palette and confirm the reason reads “Already acknowledged.” Your button should use the same check.
Leave the component and confirm its action disappears.

## Errors

<Callout type="error" title="expected a name of letters, digits and hyphens">

```text shared
alert-panel failed to register action: expected a name of letters, digits and hyphens starting
with a letter (for example "refresh"), received "acknowledge alert".
```

**Fix.** Rename the action to `acknowledge-alert`. Spaces, dots and colons are not allowed.

</Callout>

<Callout type="error" title="expected one registration per action name within a mount">

```text shared
alert-panel failed to register action 'refresh': expected one registration per action name
within a mount, received a second registration of 'refresh' in the same mount.
```

**Fix.** Rename one of the two. Neither is dropped in favour of the other, so the second one
throws instead.

</Callout>

<Callout type="error" title="expected a non-empty label">

```text shared
alert-panel failed to register action 'refresh': expected a non-empty label, received an empty
string.
```

**Fix.** Give the action the words you want in the palette. It is the only text the reader sees.

</Callout>
