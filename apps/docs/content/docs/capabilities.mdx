Use this index to find a task and its framework-specific API. The shell supplies shared services when it mounts your App or Widget.

## Connect your container to the shell

React APIs link to their reference entries. Angular injectors are listed in the [mount API reference](/docs/reference/angular-adapter#read-the-shell-from-inside-a-mount).
Call React hooks during render. Call Angular injectors in an injection context, such as a component field initializer.

| What you need                                | React API                                                                                                                | Angular API                                   | Task guide                                                                                                                   |
| -------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------ | --------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------- |
| Show a command in the palette                | [`useAction`](/docs/reference/hooks-and-components#useaction)                                                            | `injectAction`                                | [Add an action](/docs/add-an-action)                                                                                         |
| Offer a command to the agent                 | [`useAction`](/docs/reference/hooks-and-components#useaction)                                                            | `injectAction`                                | [Offer an action](/docs/offer-an-action-to-the-agent)                                                                        |
| Tell the agent what is selected              | [`useAgentContext`](/docs/reference/hooks-and-components#useagentcontext)                                                | `injectAgentContext`                          | [Publish selection context](/docs/tell-the-agent-what-is-selected)                                                           |
| Set the shell's breadcrumb trail             | [`useBreadcrumbs`](/docs/reference/hooks-and-components#usebreadcrumbs)                                                  | `injectBreadcrumbs`                           | [Set breadcrumbs](/docs/set-breadcrumbs)                                                                                     |
| Confirm leaving unsaved changes              | [`useNavigationBlock`](/docs/reference/hooks-and-components#usenavigationblock)                                          | `injectNavigationBlock`                       | [Block navigation](/docs/block-navigation-when-unsaved)                                                                      |
| Read identity and group membership           | [`useUser`](/docs/reference/hooks-and-components#useuser), [`useGroups`](/docs/reference/hooks-and-components#usegroups) | `injectUser`, `injectGroups`                  | [Shell state reference](/docs/reference/hooks-and-components#shell-state)                                                    |
| Read the current theme                       | [`useTheme`](/docs/reference/hooks-and-components#usetheme)                                                              | `injectTheme`                                 | [Follow the shell theme](/docs/follow-the-shell-theme)                                                                       |
| Save a definition's own preference           | [`useStoredState`](/docs/reference/hooks-and-components#usestoredstate)                                                  | `injectStoredState`                           | [Remember a value](/docs/remember-a-value)                                                                                   |
| Read or write browser storage outside render | [`useMfeStorage`](/docs/reference/hooks-and-components#usemfestorage)                                                    | `injectMfeStorage`                            | [Storage outside render](/docs/storage-outside-render)                                                                       |
| Synchronize values across definitions        | `useSharedState`, `useSharedStateStore`                                                                                  | `injectSharedState`, `injectSharedStateStore` | [Share state](/docs/shared-state)                                                                                            |
| Cancel work when the mount ends              | [`useMfeSignal`](/docs/reference/hooks-and-components#usemfesignal)                                                      | `injectMfeSignal`                             | [Cancel a request](/docs/cancel-a-request-on-unmount)                                                                        |
| Record events, errors, and traces            | [`useTelemetry`](/docs/reference/hooks-and-components#usetelemetry)                                                      | `injectTelemetry`                             | [Log an event](/docs/log-an-event), [report an error](/docs/report-an-error), [trace an operation](/docs/trace-an-operation) |
| Call your API with the shell session         | `fetch` from `#mfe/fetch`                                                                                                | `fetch` from `#mfe/fetch`                     | [Call your API](/docs/call-your-api)                                                                                         |
| Declare settings or help pages               | `staticData.capability`                                                                                                  | `mfeRouteData({ capability })`                | [Settings](/docs/add-a-settings-page), [help](/docs/add-a-help-page)                                                         |

Shared-state bindings come from generated `#mfe/shared-state` modules. They require a declared schema and [shell configuration](/docs/configure-shared-state).
Browser storage keeps values under a definition's scope. Shared state synchronizes named values between participating definitions.
