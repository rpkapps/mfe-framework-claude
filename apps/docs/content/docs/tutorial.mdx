description: 'Declare an App, add a route that calls your API, publish a settings page and release notes, render a Widget from another container, and test it.'

Build an operations App in your own repository, using the published framework packages. Complete the [quickstart setup](/docs/quickstart) first.
By the end you have four things:

- a routed App on its own stretch of the URL,
- two pages the shell opens for you,
- a Widget from another container rendered inside yours,
- a test that passes.

React examples adapt the repository's Operations sample. The file paths below belong to your consumer container.
Angular tabs show equivalent files for your generated Nx project.
Start Angular with the [Nx generator](/docs/reference/mfe-nx#generate-a-container), then add the files shown below.
Add Angular route objects to the same `routes` array as you progress.

## Steps

<Steps>

<Step>

### 1. Declare the App

<Tabs items={['React', 'Angular']}>
<Tab value="React">

```ts title="src/mfe.ts"
import { createApp, type AppRouterOptions } from '@company/mfe-react'
import { HardHatIcon } from 'lucide-react'
import { createRouter } from '@tanstack/react-router'

import { routeTree } from './routeTree.gen'

function makeRouter({ basePath, history, context }: AppRouterOptions) {
  return createRouter({
    routeTree,
    basepath: basePath,
    history,
    context: { ...context },
    defaultPreload: 'intent',
  })
}

export default createApp({
  id: 'operations',
  version: '2.1.0',
  description: 'Day-to-day field operations: wells, alerts and daily reports.',
  icon: HardHatIcon,
  router: makeRouter,
})
```

</Tab>
<Tab value="Angular">

```ts title="src/mfe.ts"
import { createApp } from '@company/mfe-angular'
import { routes } from './app.routes'

export default createApp({ id: 'operations', version: '2.1.0', routes })
```

</Tab>
</Tabs>

`router` is a factory the framework calls for each mount, twice in development under StrictMode, so it builds the router and does nothing else. Forward all three arguments: `basePath`
as `basepath`, the `history` as it arrived, and the `context` spread into your own. Add your own
top-level context keys freely.

</Step>

<Step>

### 2. Add a route

<Tabs items={['React', 'Angular']}>
<Tab value="React">

```tsx title="src/routes/assets.tsx"
import { createFileRoute } from '@tanstack/react-router'
import { useSuspenseQuery } from '@tanstack/react-query'
import { z } from 'zod'

import { assetsQueryOptions } from '../queries/assets.ts'

export const Route = createFileRoute('/assets')({
  staticData: { breadcrumb: 'Assets' },
  validateSearch: z.object({ site: z.enum(['north', 'south', 'central']).default('north') }),
  loaderDeps: ({ search }) => ({ site: search.site }),
  loader: ({ context, deps }) => context.queryClient.ensureQueryData(assetsQueryOptions(deps.site)),
  component: Assets,
})

function Assets() {
  const { site } = Route.useSearch()
  const { data } = useSuspenseQuery(assetsQueryOptions(site))

  return (
    <ul>
      {data.map(asset => (
        <li key={asset.id}>{asset.name}</li>
      ))}
    </ul>
  )
}
```

</Tab>
<Tab value="Angular">

```ts title="src/assets.component.ts"
import { Component, inject } from '@angular/core'
import { ActivatedRoute } from '@angular/router'

@Component({
  selector: 'operations-assets',
  template: `<ul>
    @for (asset of assets; track asset.id) {
      <li>{{ asset.name }}</li>
    }
  </ul>`,
})
export class AssetsComponent {
  readonly assets = inject(ActivatedRoute).snapshot.data['assets'] as { id: string; name: string }[]
}
```

```ts title="src/app.routes.ts"
import { inject } from '@angular/core'
import { type ResolveFn, type Routes } from '@angular/router'
import { injectTelemetry } from '@company/mfe-angular'
import { fetch } from '#mfe/fetch'
import { AssetsComponent } from './assets.component'

const assetsResolver: ResolveFn<unknown> = async route => {
  const telemetry = injectTelemetry()
  const site = route.queryParamMap.get('site') ?? 'north'
  telemetry.debug('Loading assets', { site })
  const response = await fetch(`assets?site=${encodeURIComponent(site)}`)
  if (!response.ok) throw new Error(`Loading assets failed: ${response.status}`)
  return response.json()
}

export const routes: Routes = [
  { path: 'assets', component: AssetsComponent, resolve: { assets: assetsResolver } },
]
// AssetsComponent reads its result from ActivatedRoute.snapshot.data['assets'].
```

</Tab>
</Tabs>

Write the path relative to your boundary. This route is `/assets`, never `/operations/assets`. The
`queryClient` on the context belongs to your mount, so the loader and the component share one cache
entry.

</Step>

<Tabs items={['React', 'Angular']}>
<Tab value="React">

```ts title="src/queries/assets.ts"
import { queryOptions } from '@tanstack/react-query'
import { fetch } from '#mfe/fetch'
import { z } from 'zod'

const assetSchema = z.object({
  id: z.string(),
  name: z.string(),
  status: z.enum(['operational', 'degraded', 'offline']),
})

export function assetsQueryOptions(siteId: string) {
  return queryOptions({
    queryKey: ['operations', 'assets', { siteId }],
    queryFn: async ({ signal }): Promise<z.infer<typeof assetSchema>[]> => {
      const response = await fetch(`assets?site=${encodeURIComponent(siteId)}`, { signal })
      if (!response.ok) throw new Error(`Loading assets failed with ${response.status}.`)
      return z.array(assetSchema).parse(await response.json())
    },
    staleTime: 30_000,
  })
}
```

</Tab>
<Tab value="Angular">

```ts title="src/assets.ts"
import { fetch } from '#mfe/fetch'
import { z } from 'zod'

const assetSchema = z.object({
  id: z.string(),
  name: z.string(),
  status: z.enum(['operational', 'degraded', 'offline']),
})

export async function fetchAssets(siteId: string, signal?: AbortSignal) {
  const response = await fetch(`assets?site=${encodeURIComponent(siteId)}`, { signal })
  if (!response.ok) throw new Error(`Loading assets failed with ${response.status}.`)
  return z.array(assetSchema).parse(await response.json())
}
```

</Tab>
</Tabs>

`src/mfe.config.ts` declares names and schemas, never values. The values arrive in the deployed
`runtime-config.json`. A relative request through `#mfe/fetch` resolves against the field marked
`{ api: true }`, and only those origins receive the session token.

</Step>

### 4. Mark the settings page

<Tabs items={['React', 'Angular']}>
<Tab value="React">

```tsx title="src/routes/settings.tsx"
import { createFileRoute } from '@tanstack/react-router'

import { SettingsPage } from '../components/settings-01/page.tsx'

export const Route = createFileRoute('/settings')({
  staticData: {
    capability: {
      name: 'settings',
      label: 'Operations settings',
      icon: 'settings',
    },
    breadcrumb: 'Settings',
  },
  component: SettingsPage,
})
```

</Tab>
<Tab value="Angular">

```ts title="src/app.routes.ts"
import type { Routes } from '@angular/router'
import { mfeRouteData } from '@company/mfe-angular'
import { SettingsComponent } from './settings.component'

export const routes: Routes = [
  {
    path: 'settings',
    component: SettingsComponent,
    data: mfeRouteData({
      capability: {
        name: 'settings',
        label: 'Operations settings',
        icon: 'settings',
      },
    }),
  },
]
```

</Tab>
</Tabs>

A capability page is an ordinary route with a marker on it. The build extracts the marker into your
registry entry, and the shell decides where the page opens. The path comes from `createFileRoute`,
and the `capability` object says which page it is and what the shell calls it.

</Step>

### 6. Render a Widget from another container

Install the provider's published contract package in your consumer repository. The sample uses `@example/alert-panel/contracts`.
Use your team's package name and compatible published version. Register the Widget container with the shell independently.

<Tabs items={['React', 'Angular']}>
<Tab value="React">

```ts title="src/widgets.ts"
import { lazyWidget } from '@company/mfe-react'

import { inputSchema, outputSchema } from '@example/alert-panel/contracts'

export const AlertPanel = lazyWidget('alert-panel', { contract: { inputSchema, outputSchema } })
```

</Tab>
<Tab value="Angular">

```ts title="src/alert-consumer.component.ts"
import { Component } from '@angular/core'
import { MfeWidgetComponent } from '@company/mfe-angular'
import { inputSchema, outputSchema } from '@example/alert-panel/contracts'

@Component({
  selector: 'alert-consumer',
  imports: [MfeWidgetComponent],
  template: `<mfe-widget
    widgetId="alert-panel"
    [contract]="contract"
    [inputs]="{ alertId: 'a-1001', severity: 'warning' }"
  />`,
})
export class AlertConsumer {
  readonly contract = { inputSchema, outputSchema }
}
```

</Tab>
</Tabs>

<Tabs items={['React', 'Angular']}>
<Tab value="React">

```tsx title="src/routes/index.tsx"
import { useState } from 'react'

import { AlertPanel } from '../widgets.ts'

function Overview() {
  const [acknowledged, setAcknowledged] = useState<string | null>(null)

  return (
    <>
      <AlertPanel
        alertId="a-1001"
        severity="warning"
        pending={<p>Loading the alert panel…</p>}
        onAcknowledged={payload => {
          setAcknowledged(payload.acknowledgedAt)
        }}
      />
      {acknowledged === null ? null : <p>Acknowledged at {acknowledged}.</p>}
    </>
  )
}
```

</Tab>
<Tab value="Angular">

```ts title="src/alert-consumer.component.ts"
import { Component, signal } from '@angular/core'
import { MfeWidgetComponent, type MfeWidgetOutput } from '@company/mfe-angular'
import { inputSchema, outputSchema, type Outputs } from '@example/alert-panel/contracts'

@Component({
  selector: 'alert-consumer',
  imports: [MfeWidgetComponent],
  template: `<mfe-widget
      widgetId="alert-panel"
      [contract]="contract"
      [inputs]="{ alertId: 'a-1001', severity: 'warning' }"
      [pending]="loading"
      [fallback]="failed"
      (output)="onOutput($event)"
    />
    <ng-template #loading>Loading alert…</ng-template>
    <ng-template #failed let-error let-retry="retry">
      <p role="alert">{{ error.message }}</p>
      <button (click)="retry()">Retry</button>
    </ng-template>`,
})
export class AlertConsumer {
  readonly contract = { inputSchema, outputSchema }
  readonly acknowledged = signal<string | null>(null)

  onOutput(event: MfeWidgetOutput) {
    if (event.name === 'acknowledged') {
      const payload = outputSchema.shape.acknowledged.parse(event.payload)
      this.acknowledged.set(payload.acknowledgedAt)
    }
  }
}
```

</Tab>
</Tabs>

Call `lazyWidget` at module scope, once. A Widget's inputs are ordinary props, and each output it
declares arrives as an `onX` prop. `pending` fills the space while the other container is fetched.

</Step>

<Step>

### 7. Write a test

<Tabs items={['React', 'Angular']}>
<Tab value="React">

```tsx title="src/routes/assets.test.tsx"
import { renderApp, setMfeApiBaseUrl, setMfeConfig, setMfeFetch } from '@company/mfe-react/testing'
import { screen, waitFor } from '@testing-library/react'
import { expect, it } from 'vitest'

import operations from '../mfe.ts'

const API = 'https://api.example.test/v1/'

it('renders what the API returned', async () => {
  setMfeConfig({ apiBaseUrl: API, telemetryEnabled: false })
  setMfeApiBaseUrl(API)
  setMfeFetch(
    () => new Response(JSON.stringify([{ id: 'a-1', name: 'Pump 4', status: 'operational' }])),
  )

  const rendered = renderApp(operations, { initialEntries: ['/assets'] })

  await waitFor(() => {
    expect(screen.getByText('Pump 4')).toBeInTheDocument()
  })

  await rendered.dispose()
})
```

</Tab>
<Tab value="Angular">

```ts title="src/assets.spec.ts"
import { mountApp, setMfeApiBaseUrl, setMfeConfig, setMfeFetch } from '@company/mfe-angular/testing'
import { expect, it } from 'vitest'
import operations from './mfe'

const API = 'https://api.example.test/v1/'

it('renders what the API returned', async () => {
  setMfeConfig({ apiBaseUrl: API, telemetryEnabled: false })
  setMfeApiBaseUrl(API)
  setMfeFetch(
    () => new Response(JSON.stringify([{ id: 'a-1', name: 'Pump 4', status: 'operational' }])),
  )
  const mounted = await mountApp(operations, {
    basePath: '/operations',
    initialEntries: ['/operations/assets'],
  })
  try {
    await mounted.whenStable()
    expect(mounted.element.textContent).toContain('Pump 4')
  } finally {
    await mounted.dispose()
  }
})
```

</Tab>
</Tabs>

`renderApp` runs the real adapter over a memory history and in-memory stores. Your source keeps its
production imports, and the test runner points `#mfe/config` and `#mfe/fetch` at fixtures. Dispose
the render, so the next test starts clean.

</Step>

Start the shell separately in its own repository. Your dev command starts only your container.

</Step>

## Check it works

Open `/operations` at your separately running shell's origin. The shell chrome stays above your App, and the alert panel
renders inside your overview from another deployment. Go to `/operations/assets`, change the site,
and the URL carries the choice. Press <Kbd>⌘</Kbd><Kbd>K</Kbd>: **Operations settings** and
**Operations release notes** are listed under **Application pages**. The shell's own settings panel
lists the settings page under **Application settings**. Run your React package's test script or the Angular consumer workspace's `nx test operations` target.

## Errors

<Callout type="error" title="a non-empty label string literal">

```text shared
failed to extract the capability route '/release-notes': expected a non-empty `label` string
literal, found no label.
```

**Fix.** Add `label` inside the `capability` object, as an inline string. The build reads it without running
your code, so it cannot be computed.

</Callout>
