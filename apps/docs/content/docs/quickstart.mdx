---
title: 'Quickstart'
description: 'Scaffold a container, start the shell, and watch your own App mount into it. About ten minutes.'
---

Run a React or Angular App inside the shell. React scaffolds a new container. Angular starts with the bundled Fieldwork example.
For your own Angular container, use the [Nx generator](/docs/reference/mfe-nx#generate-a-container) in an Nx workspace.

## Steps

<Steps>

<Step>

### 1. Choose a container

<Tabs items={['React', 'Angular']}>
<Tab value="React">

```sh
pnpm create @company/mfe examples/field-notes --id field-notes
```

</Tab>
<Tab value="Angular">

```sh title="terminal"
# The Angular example is already present in this repository.
cd examples/fieldwork
cat src/mfe.ts
cd ../..
```

</Tab>
</Tabs>

Run commands from the repository root. React ids use lower-case letters, digits and single hyphens. Pass `--template widget` for a React Widget.

</Step>

<Step>

### 2. Install the new package

```sh shared
pnpm install
```

`examples/*` is a workspace folder. Installation links the React scaffold and the bundled Angular packages.

</Step>

<Step>

### 3. Generate the registry

```sh shared
pnpm run generate
```

Every container writes its own registry entry, and the root script assembles them into
`apps/shell/public/registry.json`. Nobody hand-writes that file.

</Step>

<Step>

### 4. Start the shell and every container

```sh shared
pnpm dev
```

The shell serves `http://localhost:3000`. Each container serves its own port. A React scaffold takes 3101. The Angular Fieldwork example uses 3007.

</Step>

<Step>

### 5. Open your App

<Tabs items={['React', 'Angular']}>
<Tab value="React">

```text
http://localhost:3000/field-notes
```

</Tab>
<Tab value="Angular">

```text title="browser address"
http://localhost:3000/fieldwork
```

</Tab>
</Tabs>

The shell owns `/` and `/$appId`. Everything below your id is yours to route.

</Step>

</Steps>

## Check it works

The shell chrome stays at the top, and your App renders below it. The React scaffold and Angular Fieldwork example show the signed-in user. Press <Kbd>⌘</Kbd><Kbd>K</Kbd> to open
the palette. Your App is listed under **Go to**, and the settings page the scaffold wrote is listed
under **Application pages** as `field-notes settings` or `Fieldwork settings`.

## Errors

<Callout type="error" title="Port 3000 already in use">

```text shared
Port 3000 already in use.
```

**Fix.** A dev server from an earlier run still holds it. The message prints the `lsof` command that
names the process, and `kill <pid>` stops it.

</Callout>

<Callout type="error" title="not a usable definition id">

```text shared
"Field_Notes" is not a usable definition id. Ids are lower-case letters, digits and single hyphens,
for example "alert-panel".
```

**Fix.** Pass `--id field-notes`. The id is also your storage prefix and your CSS scope value.

</Callout>

<Callout type="error" title="Nothing generated">

```text shared
Nothing generated for field-notes. Run `pnpm run generate` first: the registry is assembled
from what each container generates, never hand-written.
```

**Fix.** Run `pnpm install`, then `pnpm run generate` again. The container needs its dependencies
before it can generate anything.

</Callout>
