---
title: 'Create a Widget'
description: 'Declare a Widget in src/mfe.ts, with its render function in its own module.'
---

A Widget is a screen somebody else's page renders as a component: it takes props, emits the
outputs it declares, and owns no URL. One container can export any number of Widgets.

## Steps

<Steps>

<Step>

### 1. Write the render function

<Tabs items={['React', 'Angular']}>
<Tab value="React">

```tsx title="examples/alert-panel/src/alert-panel.tsx (trimmed)"
import type { WidgetRenderProps } from '@company/mfe-react'
import { Button } from '@tecton/react/components/button'
import type { ReactNode } from 'react'

import type { alertPanelContract } from './mfe.ts'

export function AlertPanel({
  inputs,
  emit,
}: WidgetRenderProps<typeof alertPanelContract>): ReactNode {
  return (
    <>
      <p>Alert {inputs.alertId}</p>
      <Button
        onClick={() => {
          emit('acknowledged', {
            alertId: inputs.alertId,
            acknowledgedAt: new Date().toISOString(),
          })
        }}
      >
        Acknowledge
      </Button>
    </>
  )
}
```

</Tab>
<Tab value="Angular">

```ts title="src/alert-panel.component.ts"
import { Component, input, output } from '@angular/core'

@Component({
  selector: 'alert-panel',
  template: `<p>Alert {{ alertId() }}</p>
    <button (click)="acknowledge()">Acknowledge</button>`,
})
export class AlertPanelComponent {
  readonly alertId = input.required<string>()
  readonly severity = input<'info' | 'warning' | 'critical'>('info')
  readonly acknowledged = output<{ alertId: string; acknowledgedAt: string }>()
  readonly dismissed = output<{ alertId: string }>()

  acknowledge() {
    this.acknowledged.emit({
      alertId: this.alertId(),
      acknowledgedAt: new Date().toISOString(),
    })
  }
}
```

</Tab>
</Tabs>

React receives `inputs` and `emit` in its render function. Keep it in a module that exports components only.
Angular declares matching component inputs and outputs. Every schema field must have a component member.

</Step>

<Step>

### 2. Declare the Widget in the entry

<Tabs items={['React', 'Angular']}>
<Tab value="React">

```ts title="examples/alert-panel/src/mfe.ts"
import { createWidget } from '@company/mfe-react'
import { BellIcon } from 'lucide-react'
import { z } from 'zod'

import { AlertPanel } from './alert-panel.tsx'

export const alertPanelContract = {
  inputSchema: z.object({
    alertId: z.string(),
    severity: z.enum(['info', 'warning', 'critical']).default('info'),
  }),
  outputSchema: z.object({
    acknowledged: z.object({ alertId: z.string(), acknowledgedAt: z.string() }),
    dismissed: z.object({ alertId: z.string() }),
  }),
}

export const alertPanel = createWidget({
  id: 'alert-panel',
  version: '1.4.0',
  title: 'Alert panel',
  description: 'Open alerts for one asset, acknowledged or dismissed in place.',
  tags: ['alerts', 'operations', 'safety'],
  icon: BellIcon,
  ...alertPanelContract,
  render: AlertPanel,
})
```

</Tab>
<Tab value="Angular">

```ts title="src/mfe.ts"
import { createWidget } from '@company/mfe-angular'
import { z } from 'zod'
import { AlertPanelComponent } from './alert-panel.component'

export const alertPanelContract = {
  inputSchema: z.object({
    alertId: z.string(),
    severity: z.enum(['info', 'warning', 'critical']).default('info'),
  }),
  outputSchema: z.object({
    acknowledged: z.object({ alertId: z.string(), acknowledgedAt: z.string() }),
    dismissed: z.object({ alertId: z.string() }),
  }),
}

export const alertPanel = createWidget({
  id: 'alert-panel',
  version: '1.4.0',
  title: 'Alert panel',
  ...alertPanelContract,
  component: AlertPanelComponent,
})
```

</Tab>
</Tabs>

The build reads `src/mfe.ts` and no other file, so export every definition from it and write
`id`, `version`, `title`, `description` and `tags` as plain literals.

</Step>

<Step>

### 3. Give the container a port and its ids

```json title="examples/alert-panel/package.json" shared
"mfe": {
  "port": 3003,
  "definitions": ["alert-panel"]
}
```

`port` is this container's dev-server port, and `definitions` lists the ids `pnpm dev` prints a
shell override for.

</Step>

</Steps>

## Check it works

Run `pnpm dev` from the repository root, then open the shell at `http://localhost:3000`. The
dashboard's catalogue lists your Widget by the `title`, `description` and `tags` you declared,
before anything loads it. Add it from the catalogue to mount it on the page. If your definition declares an icon, the catalogue draws its published shapes beside the name.

## Errors

<Callout type="error" title="registry/invalid-entry">

```text shared
Order_Book failed to createWidget: expected lower-case letters, digits and single hyphens (for
example "alert-panel"), received "Order_Book".
```

**Fix.** Rename the id to `order-book`. The id is also your storage prefix and your CSS scope.

</Callout>

<Callout type="error" title="mount/failure">

```text shared
alert-panel failed to create Widget definition: expected a render function, received nothing.
```

**Fix.** Pass `render: AlertPanel`, imported from its own module.

</Callout>

<Callout type="error" title="registry/invalid-entry, at build time">

```text shared
/home/you/alert-panel/src/alert-panel.tsx:12:20: the build failed to collect the definitions this
container exports: expected every definition to be declared in src/mfe.ts, found createWidget(…)
in another module.
```

**Fix.** Move the `createWidget` call into `src/mfe.ts` and export it from there.

</Callout>
