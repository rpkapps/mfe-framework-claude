---
title: 'Embed another App inside yours'
description: 'Hand a branch of your URL to another App with mfeRoute, and let it route everything below that point.'
---

Apps only. One route of yours hands a branch of the address bar to another App. That App routes
everything below the branch and never learns where you put it.

## Steps

<Steps>

<Step>

### 1. Hand over at a splat route

<Tabs items={['React', 'Angular']}>
<Tab value="React">

```ts title="examples/operations/src/routes/reports.$.tsx"
import { createFileRoute } from '@tanstack/react-router'
import { mfeRoute } from '@company/mfe-react'

export const Route = createFileRoute('/reports/$')(mfeRoute({ appId: 'reports' }))
```

</Tab>
<Tab value="Angular">

```ts title="src/app.routes.ts"
import type { Routes } from '@angular/router'
import { mfeAppRoute } from '@company/mfe-angular'

export const routes: Routes = [mfeAppRoute({ appId: 'reports', path: 'reports' })]
```

</Tab>
</Tabs>

React delegates through a splat route. Angular's `mfeAppRoute` adds the wildcard child for you.
Both mount Reports at `/operations/reports` and let it handle paths below that boundary.

</Step>

<Step>

### 2. Link to it

<Tabs items={['React', 'Angular']}>
<Tab value="React">

```tsx title="examples/operations/src/routes/__root.tsx"
void navigate({ to: '/reports/$', params: { _splat: '' } })
```

</Tab>
<Tab value="Angular">

```ts title="src/navigation.component.ts"
import { inject } from '@angular/core'
import { Router } from '@angular/router'

// Component field initializer: this router belongs to the mounted App.
readonly router = inject(Router)

openReports() {
  void this.router.navigate(['/reports'])
}
```

</Tab>
</Tabs>

Your App's router reaches the delegated route. React passes an empty splat. Angular navigates to `/reports`. Both open the child's index page.

</Step>

<Step>

### 3. Draw your own box when it fails

<Tabs items={['React', 'Angular']}>
<Tab value="React">

```tsx title="examples/operations/src/routes/reports.$.tsx"
export const Route = createFileRoute('/reports/$')({
  ...mfeRoute({ appId: 'reports' }),
  errorComponent: ReportsUnavailable,
})
```

</Tab>
<Tab value="Angular">

```ts title="src/reports-host.component.ts"
import { Component } from '@angular/core'
import { MfeAppHostComponent, mfeAppRoute } from '@company/mfe-angular'

@Component({
  selector: 'reports-host',
  imports: [MfeAppHostComponent],
  template: `<mfe-app-host [pending]="loading" [fallback]="failed" />
    <ng-template #loading>Loading reports…</ng-template>
    <ng-template #failed let-error let-retry="retry">
      <p>{{ error.message }}</p>
      <button (click)="retry()">Retry</button>
    </ng-template>`,
})
export class ReportsHost {}

export const routes = [
  { ...mfeAppRoute({ appId: 'reports', path: 'reports' }), component: ReportsHost },
]
```

</Tab>
</Tabs>

React merges an `errorComponent` into `mfeRoute` options. Angular supplies a wrapper with pending and fallback templates.
A child failure leaves the rest of your App running.

</Step>

</Steps>

## Check it works

Start the parent and child containers with their own development scripts, register both in the
separately running shell, and open the parent's embedding route. Confirm the child renders inside
the parent page and that its navigation stays below the embedding prefix. For the example above,
a parent mounted at `/operations` gives the child `/operations/reports`; an account route should
resolve below that boundary. If the host also mounts the child at its own top-level boundary,
confirm that placement works independently.

Per-instance data goes through the child's own URL, as a path segment or a search parameter. An
App takes no props. A screen that needs props is a Widget.

## Errors

<Callout type="error" title="no registry entry with this id">

```text shared
reports failed to resolve App: no registry entry with this id. Check the id against the generated
registry entry, or add a localStorage override pointing at your dev server.
```

**Fix.** Check the spelling of `appId` against the registry. In development, point the shell at
the child's dev server.

</Callout>

<Callout type="error" title="expected an entry for an App">

```text shared
reports failed to resolve App: expected an entry for an App, received an entry for a Widget, which
owns no URL boundary.
```

**Fix.** The id names a Widget. Render it with `lazyWidget` instead, or name the App you meant.

</Callout>
