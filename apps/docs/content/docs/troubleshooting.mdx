Start with the symptom you see. If a message includes an error code, look up that code in the [error reference](/docs/reference/error-codes).

## Find a fix by symptom

| Symptom                                           | First check                                                           | Guide or reference                                                                                                                                                                          |
| ------------------------------------------------- | --------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| My container is missing from the shell            | Check the Registry tab for entries set aside at boot.                 | [Open devtools](/docs/open-the-devtools), [registry errors](/docs/reference/error-codes#registry-and-contract-codes)                                                                        |
| My App or Widget fails to load                    | Check the manifest URL, remote entry, and runtime compatibility.      | [Loading errors](/docs/reference/error-codes#loading-and-lifecycle-codes), [read a failure message](/docs/read-a-failure-message)                                                           |
| My App fails to mount or routes incorrectly       | Check the assigned boundary and your router configuration.            | [Create an App](/docs/create-an-app#errors), [Angular App declaration](/docs/reference/angular-adapter#declare-an-app)                                                                      |
| A hook or injector throws `mount/failure`         | Check that it runs in a supported mount or host context.              | [React call locations](/docs/reference/hooks-and-components#where-each-hook-may-be-called), [Angular injection context](/docs/reference/angular-adapter#read-the-shell-from-inside-a-mount) |
| A Widget rejects inputs or outputs                | Compare values and output names with its declared schemas.            | [Define inputs and outputs](/docs/define-inputs-and-outputs), [contract errors](/docs/reference/error-codes#registry-and-contract-codes)                                                    |
| My action is missing or cannot run                | Check its registration, `canExecute`, and input schema.               | [Add an action](/docs/add-an-action), [action reference](/docs/reference/hooks-and-components#useaction)                                                                                    |
| My API request fails or lacks a token             | Check the deployment configuration and declared API URL.              | [Call your API](/docs/call-your-api), [configuration errors](/docs/reference/error-codes#configuration-and-network-codes)                                                                   |
| My shared-state update is rejected                | Check the value's schema, persistence failure, and concurrent writes. | [Shared-state errors](/docs/shared-state#errors), [shell configuration](/docs/configure-shared-state)                                                                                       |
| A browser preference cannot be read or saved      | Check its schema and the browser's storage availability.              | [Remember a value](/docs/remember-a-value), [storage errors](/docs/reference/error-codes#router-action-and-storage-codes)                                                                   |
| A dialog or tooltip loses its styling             | Check that its portal renders inside the mount's overlay root.        | [Render dialogs and tooltips](/docs/render-dialogs-and-tooltips), [Angular PrimeNG](/docs/reference/angular-adapter#use-primeng)                                                            |
| An Angular field changes but the view stays stale | Use signals or call `markForCheck()` for rendered state.              | [Angular change detection](/docs/reference/angular-adapter#zoneless-and-nothing-else)                                                                                                       |
| React edits reload the whole page                 | Keep component exports separate from schemas and definitions.         | [Keep hot updates working](/docs/keep-hot-updates-working)                                                                                                                                  |
| My local container never appears                  | Check the dev-server origin and the shell's local override.           | [Point the shell at your dev server](/docs/point-the-shell-at-your-dev-server)                                                                                                              |

## Capture the failure details

Record the definition id, error code, full message, and operation that failed.
For build failures, include the file and line reported by the terminal.
Use the [devtools panel](/docs/open-the-devtools) to inspect registry entries and mount failures before changing configuration.
