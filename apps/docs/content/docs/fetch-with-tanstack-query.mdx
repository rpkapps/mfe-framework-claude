---
title: 'TanStack Query'
description: 'Reuse the React App mount Query client, or load Angular route data with generated fetch.'
---

React Apps receive a mount-owned TanStack Query client. Reuse it in loaders and components to share cached responses.
The Angular adapter does not supply a TanStack Query client. The Angular tabs show route loading with generated fetch instead.
Declare your [API URL](/docs/mark-a-url-as-your-api) before using relative requests.

## Steps

<Steps>
<Step>

### 1. Load route data with TanStack Query or Angular

<Tabs items={['React', 'Angular']}>
<Tab value="React">

```ts title="src/queries/assets.ts"
import { queryOptions } from '@tanstack/react-query'
import { fetch } from '#mfe/fetch'
import { z } from 'zod'

const assetSchema = z.object({
  id: z.string(),
  name: z.string(),
  status: z.enum(['operational', 'degraded', 'offline']),
})

export type Asset = z.infer<typeof assetSchema>

export function assetsQueryOptions(siteId: string) {
  return queryOptions({
    // Every variable that determines the response is in the key.
    queryKey: ['operations', 'assets', { siteId }],
    queryFn: async ({ signal }): Promise<Asset[]> => {
      const response = await fetch(`assets?site=${encodeURIComponent(siteId)}`, { signal })

      if (!response.ok) {
        throw new Error(
          `Loading assets for site ${siteId} failed with ${response.status} ${response.statusText}.`,
        )
      }

      return z.array(assetSchema).parse(await response.json())
    },
    staleTime: 30_000,
  })
}
```

Put every response-changing variable in the key, starting with your definition id.

</Tab>
<Tab value="Angular">

```ts title="src/assets.resolver.ts"
import type { ResolveFn } from '@angular/router'
import { injectMfeSignal } from '@company/mfe-angular'
import { fetch } from '#mfe/fetch'

export const assetsResolver: ResolveFn<unknown> = async route => {
  const signal = injectMfeSignal()
  const siteId = route.queryParamMap.get('site') ?? 'north'
  const response = await fetch(`assets?site=${encodeURIComponent(siteId)}`, { signal })
  if (!response.ok) throw new Error(`Loading assets failed: ${response.status}`)
  return response.json()
}
```

Attach this resolver as `resolve: { assets: assetsResolver }`. The Angular adapter does not supply a TanStack Query client.

</Tab>
</Tabs>
</Step>
<Step>
### 2. Read loaded data and refresh after edits

<Tabs items={['React', 'Angular']}>
<Tab value="React">

```tsx title="src/routes/assets.tsx"
import { createFileRoute } from '@tanstack/react-router'
import { useQueryClient, useSuspenseQuery } from '@tanstack/react-query'
import { assetsQueryOptions } from '../queries/assets'

export const Route = createFileRoute('/assets')({
  validateSearch: search => ({
    site: typeof search.site === 'string' ? search.site : 'north',
  }),
  loaderDeps: ({ search }) => ({ site: search.site }),
  loader: ({ context, deps }) => context.queryClient.ensureQueryData(assetsQueryOptions(deps.site)),
  component: Assets,
})

function Assets() {
  const { site } = Route.useSearch()
  const { data } = useSuspenseQuery(assetsQueryOptions(site))
  const queryClient = useQueryClient()
  return (
    <>
      <pre>{JSON.stringify(data)}</pre>
      <button
        onClick={() =>
          void queryClient.invalidateQueries({
            queryKey: ['operations', 'assets'],
          })
        }
      >
        Refresh assets
      </button>
    </>
  )
}
```

The loader and component share a cache entry. Invalidate the query after a successful edit.
Forward the supplied router context unchanged; disposal cancels that mount's queries.

</Tab>
<Tab value="Angular">

```ts title="src/overview.component.ts"
import { Component, inject } from '@angular/core'
import { ActivatedRoute } from '@angular/router'

@Component({
  selector: 'fieldwork-assets',
  template: `<p>Assets loaded for this route.</p>`,
})
export class AssetsComponent {
  readonly assets = inject(ActivatedRoute).snapshot.data['assets']
}
```

For Angular, choose your application's caching and refresh policy. Resolved data does not share the React mount's Query cache.

</Tab>

## Check it works

Mount your App in your shell and open the data route. For React, inspect the network panel: the loader and component reuse one request while its data is fresh.
Refresh after an edit and confirm the data changes. Unmounting the App cancels its running queries.
For Angular, confirm your resolver loads data before activating its route; choose your application's refresh policy separately.
