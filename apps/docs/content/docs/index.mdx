Build an **App** for a URL and its routes, or a **Widget** placed inside another page.
Your **container** is the deployable package holding those definitions. The **shell** owns the page, session, theme, and navigation around them.

## Get started

- **React:** [Quickstart](/docs/quickstart), then [build a complete App](/docs/tutorial).
- **Angular:** [Quickstart](/docs/quickstart), then [declare an App or Widget](/docs/reference/angular-adapter).
- **Shell builders:** [Architecture](/docs/architecture), then [run the shell locally](/docs/run-the-shell-locally).

Use the [React reference](/docs/reference/hooks-and-components) or [Angular reference](/docs/reference/angular-adapter) for exact APIs.
